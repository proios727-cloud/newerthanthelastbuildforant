# SCOPE: usemogul.com

- **Target:** Mogul (usemogul.com), a hosted SaaS for tracking music royalties. Version: the public site and press as of 2026-11-03.
- **Basis:** competitive research by public observation only. Mogul is a commercial product we don't own, so nothing is decompiled, scraped behind a login, or copied. The evidence is the vendor's public pages, its help center and press coverage, all read through search results.
- **Goal:** map what Mogul does for users, at the level of observable features, and find the features it doesn't appear to offer that Backstage (an artist and musician copilot) could use to stand apart.
- **Out of scope:**
  - logging in, creating accounts or calling Mogul's APIs
  - copying its code, assets, copy, branding or pricing structure
  - inferring its server-side algorithms
  - its MCP server internals

## Limits of this run

- usemogul.com is blocked by this session's network policy (proxy 403), so REA's website analysis (scripts, network calls, UI states) could **not** run. Every claim below comes from search-result summaries of public pages. Each one is marked confirmed (stated by Mogul or reported by press) or inferred.
- When this report says a feature is absent, it means "not seen in public material". It is not proof the feature doesn't exist. Re-verify on the live site once the host is allowed.
